# Managed Websites, Baja California Sur

Demo sites for the Managed Websites business: complete websites for small businesses and families in Baja California Sur, built free, owned by the client, with optional maintenance and an optional AI agent.

## Demos in this repo

- `index.html` — Showcase landing page linking the three demos.
- `real-estate/` — Demo site for a real estate agent (Baja Coast Realty, Todos Santos / El Pescadero): listings, filters, sold strip, testimonials, WhatsApp contact.
- `shop/` — Demo site for a merchant (Casa Textil, Arte y Plata, Todos Santos): blankets, silver jewelry and textiles, category filters, working cart counter, store hours.
- `family/` — Demo of a private, password protected family social platform (The Moreno Family): member profiles, family feed, photo albums, plans board. Demo password: familia2026. Front-end demo only; production uses real member accounts and server-side auth.

All businesses, people, listings and prices in the demos are fictional samples. Each demo is a single self-contained HTML file with inline CSS and JS, no build step.
